# Style engine

The style engine stores, edits, and reuses narrative style. It can turn sample text you like, knowledge-library source text, or book-analysis results into a style asset, so later chapters are more likely to keep the same language flavor, pacing, and expression limits.

## What the style engine can do for you

- Extract narrative style, language traits, and pacing habits from sample text.
- Create a style asset from knowledge-library source text or book-analysis results.
- Edit writing rules and decide which rules enter later generation.
- Bind a style to a novel so chapter generation, detection, and repair use the same style constraints.
- Work with Anti-AI rules to reduce template tone, empty phrasing, and unnatural dialogue.

## When to use it

- You already have a sample you like and want later chapters close to that flavor.
- Chapter generation can move the plot, but the language style is unstable.
- You want to learn writing technique from a reference work or book-analysis result.
- You want the prose to read like a novel, not like plot explanation.
- You want different works to keep different style assets.

## Before you start

The style engine needs a style source. Common sources are:

- Paste sample text: good when you already have a passage you like.
- Knowledge-library source text: good for extracting style from a long note or reference work.
- Book-analysis results: good for creating a style from the “Style and Technique” analysis.

The sample does not need to be very long, but it should represent the style you want. Do not mix samples with very different styles, or the extracted rules may wobble.

## Recommended path

1. Open Style engine.
2. Create a style asset.
3. Choose a source: paste text, pick knowledge-library source text, or generate from book analysis.
4. Review the extracted style traits and suggested rules.
5. Edit the rules and remove anything that does not fit this work.
6. Bind it to a novel or use it in trial writing.
7. After chapter generation, keep adjusting the style asset from the result.

## How it enters later writing

A bound style asset affects chapter generation, detection, and repair. It helps later chapters keep:

- narrative viewpoint and sentence rhythm;
- character dialogue style;
- description density and emotional expression;
- Anti-AI expression constraints;
- self-check and repair direction.

The style engine is not a one-off prompt. Treat it as a long-term asset and keep adjusting it as the work grows.

## Common questions

### Do I need a style asset before my first book?

Not necessarily. You can walk chapter generation first, then decide whether to create a style asset. The style engine is an extra capability for stability.

### Is a longer sample always better?

No. Representativeness matters more than length. A very long text raises processing cost and can mix in unrelated style. Start with a passage that shows the target style.

### When should I generate a style from book analysis?

When you have already analyzed a reference work and want to learn its style and technique. After generation, still review and edit. Do not drop every rule onto your own work unchanged.

### How is style different from Anti-AI rules?

Style is about how this book should be written. Anti-AI rules are about which expressions to avoid. They work more stably together.

### The style result is weak. What now?

Check whether the sample represents the target style, then delete rules that are too narrow or a poor fit. If needed, extract again from a more focused sample.
