# Knowledge library

The knowledge library stores notes that should keep affecting later writing: setting documents, reference works, book-analysis conclusions, character notes, world rules, and style samples. The point is that later planning, continuation, and chapter generation can keep using this material, instead of you pasting it in every time.

## What the knowledge library can do for you

- Upload and manage writing notes.
- Save published book-analysis results so that experience can enter later writing.
- See index progress and confirm a document can be searched.
- Test whether a document can be recalled.
- Archive unused notes and restore them later.
- Give novels, worlds, style, and chapter generation a long-term reference.

## When to use it

- You have setting, notes, reference text, or book-analysis conclusions that later writing should keep using.
- You are writing a long book and worry AI will forget earlier world rules or background.
- You want several reference sources in one place instead of scattered local files and chat logs.
- You want to check whether a document can actually be used by later generation.
- You want book-analysis results, style samples, and world notes to become reusable assets.

## Before you start

The knowledge library is an extra capability, not a requirement for starting a novel. You can create a novel and generate chapters without it. Turn it on when you need long-term notes, reference works, or complex setting.

Full note search usually needs a working Embedding model and vector-store connection. Follow the Settings page for the basic setup, then come back here to upload notes.

Before upload, tidy the text:

- Keep one kind of material in one document.
- Write a title that says what the note is for.
- Keep reference works, world setting, and style samples in separate documents.
- Archive notes you no longer use, so they do not interfere with later recall.

## Recommended path

1. Open Knowledge library.
2. Upload setting, reference text, or cleaned notes.
3. Watch index status until processing finishes.
4. Use a recall test to confirm the note can be found.
5. Choose or bind the note in a novel, world, book-analysis, or style flow.
6. Archive it when you stop using it; restore and rebuild the index when you need it again.

If you publish a result from Book analysis, the knowledge library stores it as a published analysis note, so you can return to the source analysis later.

## How it enters later writing

Knowledge-library notes help in several places:

- Book opening and planning: genre, setting, and reference-work information.
- World and character generation: background rules and character notes.
- Chapter writing: notes related to the current task.
- After book analysis is published: analysis conclusions can be recalled in later writing.
- Style engine: extract a style asset from knowledge-library source text.

The knowledge library is not a chapter editor. It is a long-term note warehouse: put important notes in, then let the writing chain use them when needed.

## Common questions

### Can I start writing without the knowledge library?

Yes. It is an extra capability, not a book-opening requirement. Walk the writing flow first, then add notes. That is usually better for beginners.

### Why can’t I use a document right after upload?

Upload only saves the note. The note still needs indexing before recall tests and the writing chain can use it reliably. Check index status and recent tasks first.

### What belongs in the knowledge library?

Put material you will reuse: world rules, faction notes, reference-work analysis, book-analysis conclusions, character background, style samples. Temporary inspiration can stay in the novel project.

### Can too many documents interfere with generation?

Yes. Use clear titles, archive unused notes, and choose the notes that are actually related to a novel or task.

### Does archive delete the note?

No. Archived notes leave the default use range and can be restored. After restore, you usually need to re-index before recall is stable again.

### Do I need to understand Qdrant and RAG?

No. You only need to know that after setup is complete, the knowledge library can find notes for the current task more reliably. Technical details stay in the system and Settings.
